#+begin_src R :results output graphics file :file pdf_babel/a24_mmul_diag.pdf :exports none :tangle aula24-diagnostico-modelo-linear-pt-br-figs.R
diag_plot <- function(m, titulo) {
  f <- data.frame(ajustado = fitted(m), residuo = resid(m), ordem = mmul$ordem)
  g1 <- ggplot(f, aes(ajustado, residuo)) + geom_hline(yintercept = 0, color = "gray40") +
    geom_point(alpha = .5) +
    geom_smooth(method = "loess", formula = y ~ x, se = FALSE, color = "red") +
    labs(x = "Valor ajustado (s)", y = "Resíduo (s)", title = "Resíduos vs ajustados")
  g2 <- ggplot(f, aes(sample = residuo)) + stat_qq(alpha = .5) + stat_qq_line(color = "red") +
    labs(x = "Quantis teóricos", y = "Quantis dos resíduos", title = "Q-Q normal")
  g3 <- ggplot(f, aes(ordem, residuo)) + geom_hline(yintercept = 0, color = "gray40") +
    geom_point(alpha = .5) +
    geom_smooth(method = "loess", formula = y ~ x, se = FALSE, color = "red") +
    labs(x = "Ordem de execução", y = "Resíduo (s)", title = "Resíduos vs ordem")
  (g1 | g2 | g3) + plot_annotation(title = titulo)
}

* Por que diagnosticar?

- =lm()= *sempre* devolve uma reta, mesmo para dados absurdos
- Erros padrão, ICs, \( p \)-valores e intervalos de predição *supõem* as hipóteses
  - Hipóteses violadas \to intervalos com cobertura errada, conclusões erradas

#+latex: \vfill\pause

** Resíduos: nossa janela para os erros                             :B_block:
:PROPERTIES:
:BEAMER_env: block
:END:
- Não observamos \( \varepsilon_i \); observamos os *resíduos*
  \( e_i = y_i - \hat y_i \), com \( \hat y_i = b_0 + b_1 x_i \)
- Se o modelo está certo, os resíduos devem parecer *ruído sem estrutura*
- Qualquer *padrão* nos resíduos é informação que o modelo não capturou

* Decomposição da variância

Quanto da variação de \( y \) a reta explica?

#+attr_latex: :width .95\linewidth
[[file:pdf_babel/a24_decomp.pdf]]

#+latex: \pause
\vspace{-1em}
#+begin_export latex
\[
\underbrace{\sum_{i=1}^N (y_i - \bar y)^2}_{SST\ \text{(total)}} =
\underbrace{\sum_{i=1}^N (\hat y_i - \bar y)^2}_{SSR\ \text{(regressão)}} +
\underbrace{\sum_{i=1}^N (y_i - \hat y_i)^2}_{SSE\ \text{(erro)}}
\]
#+end_export

- \( SSR \): variação *explicada* pela reta; \( SSE \): variação *não explicada*
- Vale porque \( \sum e_i = 0 \) e os resíduos são não correlacionados com \( \hat y \)
- Exemplo simples: \( 60 = 33{,}0 + 27{,}0 \)

* Coeficiente de determinação \( R^2 \)

#+begin_export latex
\[
R^2 = \frac{SSR}{SST} = 1 - \frac{SSE}{SST}
    = 1 - \frac{\text{erro conhecendo } x}{\text{erro sem conhecer } x}
\]
#+end_export

- \( 0 \le R^2 \le 1 \); na regressão simples, \( R^2 = r_{xy}^2 \) (correlação ao quadrado)
- Exemplo simples: \( R^2 = 33{,}0 / 60 = 0{,}55 \)

* Os perigos do \( R^2 \)

- \( R^2 \) mede *quanta* variância é explicada, *não* se o modelo está correto
  - =tempo ~ n= tem \( R^2 = 0{,}83 \) e está *errado* (curvatura)
- \( R^2 \) baixo pode significar ruído alto *ou* modelo ruim
  - Em física/engenharia, 0,6 é baixo; em biologia ou ciências sociais, pode ser bom
- Adicionar preditores *sempre* aumenta \( R^2 \) \to \( R^2 \) *ajustado* penaliza
  parâmetros; prefira modelos simples (parcimônia, aula 25)
- \( R^2 \) depende da *faixa* de \( x \): faixa larga \to \( R^2 \) alto, mesmo com ruído igual
- Não diz nada sobre independência, normalidade, heterocedasticidade

* Usando o modelo: predição

#+begin_src R :exports code
novo <- data.frame(n = 1000)
predict(r3, novo)                                          # 0.430 s
predict(r3, novo, interval = "confidence", level = 0.95)   # [0.417; 0.443]
predict(r3, novo, interval = "prediction", level = 0.95)   # [0.279; 0.582]
#+end_src

#+latex: \vfill\pause

Duas perguntas diferentes para \( x_p = 1000 \):
1. Qual o *tempo médio* \( \mathbb{E}[y \mid x_p] \)? \to *intervalo de confiança* (da média)
2. Quanto vai levar a *próxima execução*? \to *intervalo de predição*

#+latex: \vfill\pause

- A próxima execução tem a incerteza da reta *e* o ruído \( \varepsilon \) de uma observação
- \to O intervalo de predição é sempre *mais largo*

* IC da média vs intervalo de predição: fórmulas

Desvio padrão da predição em \( x_p \) (Jain, cap. 14), com \( S_{xx} = \sum x_i^2 - N \bar x^2 \):

#+begin_export latex
\begin{align*}
\text{média (}m\to\infty\text{):}\quad
s_{\hat y_p} &= s_e \sqrt{\frac{1}{N} + \frac{(x_p - \bar x)^2}{S_{xx}}} \\
\text{média de } m \text{ novas obs.:}\quad
s_{\hat y_{mp}} &= s_e \sqrt{\frac{1}{m} + \frac{1}{N} + \frac{(x_p - \bar x)^2}{S_{xx}}}
\end{align*}
#+end_export

Intervalo: \( \hat y_p \mp t_{[1-\alpha/2;\ N-2]}\; s \) \quad (\( m = 1 \): intervalo de predição do R)

#+latex: \vfill\pause

- O termo \( (x_p - \bar x)^2 \): incerteza *cresce* ao se afastar do centro dos dados
- Mais dados (\( N \uparrow \)) estreitam o IC da média até zero
- O intervalo de predição *nunca* fica mais estreito que \( \approx \pm 2 s_e \): o ruído
  do sistema não desaparece com mais medições

* Mensagens principais

1. Ajustar é fácil; *verificar* é o trabalho de verdade
   - Resíduos vs \( x \)/ajustados, Q-Q plot, resíduos vs ordem
2. Um \( R^2 \) alto *não* garante um modelo correto (=mmul= =tempo ~ n=, Anscombe)
3. Use conhecimento do sistema para escolher a forma do modelo (\( n^3 \))
4. Distinga *IC da média* de *intervalo de predição*
5. Não extrapole sem validar: o sistema pode mudar de regime (caches!)
